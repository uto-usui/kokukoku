# 年齢レーティング回答ガイド

App Store Connect のコンテンツレーティング質問への回答指針です。

## 目標レーティング: 4+

Kokukoku は単純なタイマーアプリであり、不適切なコンテンツは一切含みません。

## 質問と回答

App Store Connect の「Age Rating」セクションでは、以下のカテゴリについて質問されます。すべて「None（なし）」または「No（いいえ）」と回答してください。

### Apple のコンテンツ記述

| 質問 | 回答 | 理由 |
|---|---|---|
| Cartoon or Fantasy Violence | None | 暴力的な表現なし |
| Realistic Violence | None | 暴力的な表現なし |
| Prolonged Graphic or Sadistic Realistic Violence | None | 暴力的な表現なし |
| Profanity or Crude Humor | None | 不適切な言語表現なし |
| Mature/Suggestive Themes | None | 成人向けテーマなし |
| Horror/Fear Themes | None | ホラー要素なし |
| Medical/Treatment Information | None | 医療情報なし |
| Alcohol, Tobacco, or Drug Use or References | None | 該当する表現なし |
| Simulated Gambling | None | ギャンブル要素なし |
| Sexual Content and Nudity | None | 性的コンテンツなし |
| Graphic Sexual Content and Nudity | None | 性的コンテンツなし |

### 追加の質問

| 質問 | 回答 | 理由 |
|---|---|---|
| Unrestricted Web Access | No | Web ブラウジング機能なし。外部通信なし。 |
| Gambling and Contests | No | ギャンブル・コンテスト要素なし |
| Made for Kids | No | 子ども専用アプリとしては申請しない（全年齢対象だが COPPA の追加要件を避けるため）|

### 「Made for Kids」について

Kokukoku はデータ収集を行わないため技術的には子どもにも安全ですが、「Made for Kids」カテゴリでの申請は**推奨しません**。理由:

1. 「Made for Kids」を選択すると COPPA（Children's Online Privacy Protection Act）の追加コンプライアンス要件が適用される
2. Apple の Kids カテゴリには追加の審査基準がある
3. ポモドーロタイマーは主に大人・学生をターゲットにしている
4. 4+ レーティングであれば子どもも利用可能

## 結果

上記の回答により、**4+**（全年齢対象）のレーティングが自動的に算出されます。

## 注意事項

- レーティングの質問内容は Apple により変更される場合があります
- アプリのアップデート時にコンテンツが変更された場合は、レーティングの再回答が必要です
- 環境音（ピンクノイズ）の再生は、レーティングに影響するコンテンツには該当しません
