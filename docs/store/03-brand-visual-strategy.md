# Kokukoku App Store ビジュアルプレゼンテーション戦略

> 本ドキュメントは CDO / アートディレクターが策定するビジュアル戦略であり、プロダクトプランナー（01）、マーケティング（02）、ビジネス/ASO（04）、Dev/コンプライアンス（05）の各視点を統合して設計されている。

---

## 1. ブランドボイス & トーン

### 定義する5つの形容詞

**静謐（Quiet） / 端正（Precise） / 余白的（Spacious） / 無装飾（Unadorned） / 凛とした（Resolute）**

Kokukoku は「語りすぎない」ブランドである。ポモドーロタイマー市場はガチャガチャしたゲーミフィケーション系（Forest、Focus To-Do）と、ビジネスツール系（Be Focused）に二極化している。Kokukoku はそのどちらにも属さない第三極 ――「道具としての静かな美しさ」を持つプロダクトとして存在する。

### ブランドボイスの具体指針

- 一人称は使わない。主語は常に「時間」か「あなた」
- 説明的なコピーを避け、余韻を残す短文で語る
- 句読点を最小限に。体言止めを多用する
- 英語コピーは日本語から直訳せず、同じ「余白」を英語の文法で再構築する
- 有料アプリとしての品格：「無料より良い」ではなく「これしかない」という確信を伝える

### マーケティングコピーとの整合

マーケティング（02）が定めたトーン「集中は、静けさの中にある / Focus lives in stillness」をビジュアルキャプションの上位概念とする。スクリーンショットのキャプションは、この世界観の「断片」として機能する。説明文冒頭の3行（「集中は、静けさの中にある」「余計なものを一切持たない」「買い切り。サブスクリプションなし。」）が fold 前に表示される構成と、スクリーンショットのファーストビュー3枚が同時に目に入ることを前提に、メッセージの重複を避け、補完関係を作る。

| 要素 | 伝える役割 |
|---|---|
| 説明文冒頭3行 | 「何であるか」と「何でないか」（言語的理解） |
| SS1-SS3（ファーストビュー） | 「どう美しいか」と「何ができるか」（視覚的確信） |
| SS4-SS5 | 「なぜ有料の価値があるか」（エコシステム統合の証拠） |

**NG例:** 「集中力アップ！」「生産性を最大化しよう！」「かわいいタイマーアプリ」
**OK例:** 「時を刻む、ただそれだけ。」「25分が、変わる。」「Carve your time.」

## 2. ターゲットペルソナとスクリーンショットの対応

プロダクトプランナー（01）が定義した3ペルソナと、ASO（04）の3市場セグメントを掛け合わせ、各スクリーンショットが「誰の、どんな購入判断」に効くかを明確にする。

### ペルソナ別の「刺さるSS」マッピング

| SS | ペルソナA: ナレッジワーカー | ペルソナB: クリエイター | ペルソナC: 学生 | ASO セグメント |
|---|---|---|---|---|
| **SS1** ヒーロー（idle） | -- | **最重要**: UIの品質を1秒で判定する。100pt thin weight + grain texture がここで「わかってる」と伝わるか否かがすべて | -- | Craft Tool |
| **SS2** 集中中（running） | **重要**: 集中時にタイトルが消える設計思想 = 「仕事の邪魔をしない」の証拠 | **重要**: 動作中もUIの美しさが維持される確認 | -- | Craft Tool |
| **SS3** 休憩 & サイクル | -- | -- | **最重要**: ポモドーロサイクルが自動で回る = 一度始めたら手を煩わせない | No Subscription |
| **SS4** Live Activity | **重要**: Apple エコシステムへの深い統合の証拠 | -- | **最重要**: ロック画面で残り時間を確認 = アプリを開かずに勉強を続けられる | Apple Ecosystem |
| **SS5** Apple Watch + 設定 | **最重要**: Watch + MenuBar + カスタマイズ = 開発環境でシームレスに動く道具 | -- | **重要**: Watch で手元確認 = iPad 勉強中にスマホを見なくていい | Apple Ecosystem |

### 設計上の帰結

1. **SS1 はクリエイター向けの「目利きテスト」**: スクリーンショットのデザインで8割決めるペルソナB が最初に見る1枚。100pt の数字、マテリアルサーフェス、余白の取り方 ―― ここでの品質がコンバージョンに直結する
2. **SS3-SS4 は学生の「実用性確認」**: 「一度スタートしたらアプリを開かなくていい」ことを SS3（自動サイクル）と SS4（Live Activity）の2枚で証明する
3. **SS5 はナレッジワーカーの「決め手」**: iPhone + Mac + Watch の3デバイスで動く道具であることが、Things 3 や Raycast を使う層に「自分のための道具だ」と確信させる
4. **「有料の理由」は SS4-SS5 に集約**: ASO（04）の指摘「有料アプリはスクリーンショットの説得力が購入判断に直結する」に対し、SS4-SS5 でエコシステム統合の深さを見せることで「1,500円 / $9.99 の価値」を視覚的に証明する

## 3. App Store スクリーンショット戦略

### 構成枚数

| プラットフォーム | 枚数 | 理由 |
|---|---|---|
| iPhone 6.9" (1320 x 2868) | **5枚** | App Store の横スクロールで最初の3枚がファーストビュー。5枚で機能を網羅しつつ冗長にしない |
| iPhone 6.3" (1206 x 2622) | **5枚** | 6.9" と同一構成。解像度のみ差し替え |
| iPad 13" (2064 x 2752) | **4枚** | iPhone から1枚削減（MenuBarExtra は非該当） |
| Mac (最低 1280 x 800) | **4枚** | MenuBarExtra を含む macOS 固有体験を見せる |
| Apple Watch | **3枚** | タイマー idle / running / 休憩の3状態 |

### 全体のビジュアルフレームワーク

**背景:** 純白（`#FFFFFF`）のみ。ダークモードのスクリーンショットは使用しない。
理由：App Store の白い検索結果画面上で、白背景は「アプリの中身がそのまま浮かんでいる」感覚を与える。Kokukoku のマテリアルサーフェスの繊細なグレインテクスチャは白背景でこそ映える。

**デバイスフレーム:** 使わない。画面はドロップシャドウ（y:8, blur:40, 黒 opacity 0.08）で浮かせる。
理由：デバイスフレームは2020年代のストアデザインでは古い。Things 3、Bear、Raycast が採用する「フレームレス + シャドウ」が Craft Tool ユーザーの期待値。

**キャプション位置:** スクリーンショット上部、画面の外側（白背景エリア）に配置。

**キャプションの2層構造:**
- **メインキャプション:** SF Pro Display Light / ヒラギノ角ゴ W3。端末幅の 7-8%（iPhone 6.9" で約 90pt 相当）。色 `#1A1A1A`。体験を言い換える短文
- **サブキャプション:** SF Pro Text / ヒラギノ角ゴ W3。メインの 55-60% サイズ。色 `#888888`。機能的な補足を1行で。有料の理由を具体的に伝える役割

サブキャプションを追加する理由：ASO（04）の分析「有料アプリはスクリーンショットの説得力が購入判断に直結する」への対応。メインキャプションのブランドトーンを崩さずに、No Subscription ユーザーセグメントが求める「具体的に何ができるか」を補足する。

### iPhone スクリーンショット 5枚

#### SS1: ヒーロー（タイマーメイン画面 -- idle 状態）

**構図:** `25:00` が画面中央やや上。`Focus` ラベルが上に、`Start` ボタンが下に。ultraThinMaterial のグレインが見える。タイトル「Kokukoku」は tertiary color で画面上部にうっすらと。

**キャプション:**
- JA: 時を刻む、ただそれだけ。
- EN: Carve your time.

**サブキャプション:**
- JA: 買い切り。サブスクリプションなし。
- EN: One-time purchase. No subscription.

**刺さるペルソナ:** B（クリエイター） > 全ペルソナ共通
**対応 ASO セグメント:** Craft Tool / No Subscription

**意図:** 「美しいタイマー」であることを1秒で伝える。数字の大きさ（100pt thin weight）が最大の武器。サブキャプションで買い切りを即座に宣言し、「無料トライアルからのサブスク」を警戒するユーザーの心理的障壁を解除する。ファーストビューで「美しさ」と「価格モデル」を同時に伝えきる。

---

#### SS2: 集中中（タイマー running 状態）

**構図:** タイマーが `18:42` のような途中の数字を表示。「Kokukoku」タイトルは opacity 0 で消えている。`Pause` ボタンが下部に。画面全体に余白が広がり、数字だけが呼吸している。

**キャプション:**
- JA: 25分が、変わる。
- EN: 25 minutes, redefined.

**サブキャプション:**
- JA: 集中中、すべてが消える。数字だけが残る。
- EN: In focus mode, everything fades. Only the timer remains.

**刺さるペルソナ:** A（ナレッジワーカー） > B（クリエイター）
**対応 ASO セグメント:** Craft Tool

**意図:** running 状態ではタイトルが消える設計思想 = 「集中を邪魔しない」ことの証左。これは Forest（木が育つアニメーション）や Focus To-Do（タスクリストが常時表示）との明確な差別化。コードを書いている最中に視界に入っても邪魔にならない ―― ナレッジワーカーにとっての「道具の資格」。

---

#### SS3: 休憩 & サイクル（Short Break 状態）

**構図:** `Short Break` ラベルとカップの SF Symbol。`05:00` の数字。サイクルステータス（例: `2 / 4`）が小さく見える。Focus 時とは異なる穏やかなトーン。

**キャプション:**
- JA: 集中と休息の、自然なリズム。
- EN: Focus. Rest. Repeat.

**サブキャプション:**
- JA: 自動スタートで、手を煩わせない。
- EN: Auto-start keeps your flow unbroken.

**刺さるペルソナ:** C（学生） > A（ナレッジワーカー）
**対応 ASO セグメント:** No Subscription

**意図:** ポモドーロの核心 = サイクル管理の訴求。学生にとっての最大の価値は「一度始めたら勝手に回る」こと。1日8時間の勉強でタイマーを何十回も手動で操作する苦痛を、Auto-start が解消する。サブキャプションでこの実用性を明示する。

---

#### SS4: Live Activity & ロック画面

**構図:** iPhone のロック画面に Live Activity が表示されている様子。画面上部に Dynamic Island の compact 表示も小さく見せる。時刻は実際の使用場面を想起させるリアルな時間帯（14:32 など）。

**キャプション:**
- JA: 画面を閉じても、刻み続ける。
- EN: Always counting, even in your pocket.

**サブキャプション:**
- JA: ロック画面 & Dynamic Island 対応。
- EN: Lock Screen & Dynamic Island.

**刺さるペルソナ:** C（学生）= A（ナレッジワーカー）
**対応 ASO セグメント:** Apple Ecosystem

**意図:** 有料アプリとしての最大の「見える価値」。Live Activity と Dynamic Island は、無料ポモドーロアプリの大半が未対応。「閉じても動く」はスクリーンショットでしか伝えられない体験であり、1,500円の対価として最も具体的な証拠。学生は「勉強中にアプリを開きたくない」、ナレッジワーカーは「コーディング中にウィンドウを切り替えたくない」 ―― 同じ課題に対する同じ解。

---

#### SS5: Apple Watch + マルチデバイス

**構図:** 画面を縦に2分割。上半分に Apple Watch のタイマー画面（running 状態、残り時間表示）、下半分に iPhone の Settings シート（Durations、Auto-start のトグルが見える）。Watch の画面は実機スクリーンショットをモックアップに配置。

**キャプション:**
- JA: すべてのデバイスに、あなたのリズム。
- EN: Your rhythm, on every device.

**サブキャプション:**
- JA: iPhone + Mac + Apple Watch。ユニバーサル購入。
- EN: iPhone + Mac + Apple Watch. Universal Purchase.

**刺さるペルソナ:** A（ナレッジワーカー） > C（学生）
**対応 ASO セグメント:** Apple Ecosystem / No Subscription

**意図:** マルチデバイス体験とカスタマイズ性の両方を1枚で訴求。サブキャプションの「ユニバーサル購入」は ASO（04）が指摘する価格正当化の切り札 ―― 1,500円で iPhone + Mac + Watch のすべてが使える事実は、年間3,400-4,900円のサブスク型競合との比較で圧倒的に有利。「手首にも」から「すべてのデバイスに」にキャプションを変更し、Watch 単体ではなくエコシステム全体を訴求する。

## 4. App Icon の App Store での見え方

### 現在のアイコン評価

- **Light モード**: ブルー背景に白いクロックフェイス。リングに cyan-to-white のグラデーション
- **Dark モード**: 同一構図、背景がやや暗いネイビーに変化
- **Tinted モード**: 白背景に黒いクロックフェイスのみ。最もミニマル

### 所見

**強み:**
- 視認性は高い。ブルーの面積が大きく、検索結果リストで目立つ
- Tinted バリアントが秀逸。「円+L字」という最小構成で「引き算」思想と合致
- 3バリアント（Light / Dark / Tinted）を用意している点で、Apple ガイドライン遵守度が高い

**懸念と提案:**

1. **アプリ内デザイン言語との乖離:** アプリ内はモノトーンだがアイコンはビビッドなブルー
   - **提案A（保守的・推奨）:** 現状維持。ブルーは「信頼」「集中」の色彩心理として有効。発見性を担保。ASO（04）の分析でポモドーロ市場はレッドオーシャン（200+アプリ）であり、検索結果での視認性は生命線
   - **提案B（急進的）:** アイコンもモノトーン化。ブランド一貫性は最大化するが発見性は下がる。レッドオーシャンでの埋没リスクが高い

2. **時計の針のピクセル感:** 針をより細い線にし、角度を 10:10（時計業界の黄金構図）に変更する案

### スクリーンショットとアイコンの関係

App Store の検索結果では、アイコン（左）+ スクリーンショット3枚（右横スクロール）が同時に表示される。ブルーのアイコンと白背景のスクリーンショットのコントラストは、むしろ視線誘導として機能する。「アイコンで目を引き、スクリーンショットで品質を確信させる」という2段階の導線。

## 5. プレビュー動画

### 結論: **作るべき。1本のみ、15秒。**

Kokukoku の最大の差別化要素は「動いている時の静けさ」。スクリーンショットでは伝わらない。numericText transition のなめらかさ、タイトルのフェードアウト、マテリアルサーフェスの微細な動き ―― これらが「Craft you can feel」を体感させる。

ASO（04）の指摘「有料アプリはスクリーンショットの説得力が購入判断に直結する」への最強の回答がプレビュー動画。動画がある有料アプリは、ない有料アプリに比べてコンバージョン率が有意に高い。

### 構成（15秒）

| 秒数 | 内容 | ペルソナへの訴求 | 音声 |
|---|---|---|---|
| 0-3 | 黒画面からフェードイン。idle 状態の `25:00` が現れる | B: 「開いた瞬間の美しさ」 | 無音 |
| 3-5 | Start タップ。カウントダウン開始。タイトルがフェードアウト | A: 「余計なものが消える」 | 無音 |
| 5-8 | カウントダウンが進む。numericText transition がなめらかに動く | B: 「アニメーションの品質」 | 無音 |
| 8-10 | ロック画面に切り替わり、Live Activity / Dynamic Island が見える | C: 「閉じても見える」 | 無音 |
| 10-12 | macOS の MenuBarExtra が残り時間を表示している様子 | A: 「開発の邪魔をしない」 | 無音 |
| 12-14 | iPhone に戻り、Short Break 画面。サイクルが自動で回る | C: 「手を煩わせない」 | 無音 |
| 14-15 | 白背景にフェード。「Kokukoku -- 時を刻む、ただそれだけ。」 | 全ペルソナ | 無音 |

**音声なし**を強く推奨。「静けさ」がブランドなので、BGM を入れると世界観が壊れる。マーケティング（02）のトーン「集中は、静けさの中にある / Focus lives in stillness」と完全に整合する。

**フレームレート:** 60fps。numericText transition のなめらかさが命。

**書き出し:** iPhone 実機からの Screen Recording を使用。解像度は 1320 x 2868（iPhone 6.9"）で書き出し。

## 6. 全体のビジュアルコンシステンシー

### App Store プロダクトページの統一ルール

| 要素 | ルール |

### ダークモード対応

App Store のスクリーンショットはライトモードのみで統一する。ダークモード対応の訴求は説明文テキストで記載すれば十分。白背景はマテリアルサーフェスの繊細さを最大限に引き出す唯一の選択。

### プラットフォーム間の整合

iPhone / iPad / Mac のスクリーンショットは、**同じ画面状態を同じ順番で**見せる。「同じアプリの、同じ瞬間」が異なるフォームファクターで再現されている安心感が、ユニバーサル購入への信頼を補強する。

## 7. 有料アプリとしてのビジュアル説得戦略

ASO（04）の市場分析から、Kokukoku が狙う3セグメント（Craft Tool / Apple Ecosystem / No Subscription）ごとに、スクリーンショットが伝えるべき「有料の理由」を整理する。

### 3セグメント x ビジュアル証拠

| セグメント | 求めているもの | ビジュアルで伝える証拠 | 該当 SS |
|---|---|---|---|
| **Craft Tool** | 「道具としての品質」。Things 3 や Bear と同じ棚に並ぶ資格 | 100pt thin weight、グレインテクスチャ、マテリアルサーフェス。running 時のタイトル消失。デバイスフレームなしの白背景レイアウト自体が品質の証明 | SS1, SS2 |
| **Apple Ecosystem** | 「全デバイスで動く」。iPhone + Mac + Watch + Widget + Live Activity | Live Activity のロック画面表示、Dynamic Island、Apple Watch 画面、MenuBarExtra（Mac SS2）。ユニバーサル購入の明記 | SS4, SS5, Mac SS2 |
| **No Subscription** | 「一度払えば終わり」。サブスク疲れからの解放 | SS1 サブキャプションで即座に宣言。SS5 サブキャプションで「ユニバーサル購入」を明記し、1,500円で全デバイスカバーの事実を伝える | SS1, SS5 |

### 競合との視覚的差別化

App Store の検索結果で横に並ぶ競合（Forest、Focus To-Do、Session 等）との差別化ポイント:

| 競合の典型的 SS | Kokukoku の SS | 差異 |
|---|---|---|
| カラフルな背景、イラスト、アイコン装飾 | 純白背景、アプリ画面のみ | **余白の量で品質を語る** |
| 機能の箇条書きキャプション | 体験を言い換える短文キャプション | **「何ができるか」ではなく「どう感じるか」** |
| デバイスフレーム付きモックアップ | フレームなし + シャドウ | **2020年代のストアデザイン言語** |
| 複数画面のコラージュ | 1SS = 1画面状態 | **1枚1メッセージの明快さ** |

この差異が「同じ検索結果画面の中で異質に見える」ことを狙う。異質さ = 注目 = タップ。

## 8. 制作ワークフロー & 最終チェック

### 制作手順

1. **実機スクリーンショット撮影:** iPhone 16 Pro Max (6.9")、iPhone 16 Pro (6.3")、iPad Pro 13"、Mac（Retina）、Apple Watch で各状態を撮影
2. **Figma でレイアウト:** 白背景 + シャドウ + キャプション2層のテンプレートを作成し、全 SS を流し込む
3. **書き出し:** 各解像度で PNG 書き出し。圧縮は最小限（ App Store は再圧縮するため）
4. **最終確認:** 下記チェックリストで検証

### 最終チェックリスト

- [ ] 全 SS の背景が `#FFFFFF` であること
- [ ] キャプションのフォント、サイズ、色が統一ルール通りであること
- [ ] メインキャプションとサブキャプションの整合（マーケティングコピーのトーンからの逸脱がないこと）
- [ ] iPhone 6.9" / 6.3" の2サイズが揃っていること
- [ ] iPad 13" の4枚が揃っていること
- [ ] Mac のスクリーンショットが最低 1280 x 800 であること
- [ ] Apple Watch の3枚が揃っていること
- [ ] 各 SS に表示されている時刻・数字が自然であること（25:00、18:42、05:00 等）
- [ ] Live Activity の SS でロック画面の時刻がリアルな時間帯であること
- [ ] ユニバーサル購入に言及する SS5 のサブキャプションが日英両方にあること
- [ ] プレビュー動画の解像度が 1320 x 2868（iPhone 6.9"）であること
- [ ] プレビュー動画が15秒以内であること
